# Hi, I'm Henrique 👋

**BIM automation developer.** I build tools that take repetitive work off the plates of AEC teams using Autodesk Revit and Autodesk Construction Cloud.

Most of my work is in **C# / .NET**, on the **Revit API** and **Autodesk Platform Services (APS)**. I turn manual BIM workflows into reliable, one-click tools.

### 🛠️ What I work on
- **Revit add-ins:** custom ribbons, tool windows, and batch operations on sheets, views and parameters
- **Model data automation:** shared parameters, sheet reading and change plans applied safely across a project
- **ACC / BIM 360 integration:** syncing project data and documents between Revit and the cloud
- **Coordination workflows:** clash tracking and status reporting for project teams
